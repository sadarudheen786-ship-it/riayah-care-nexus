# RiayahOS Foundation

RiayahOS - Module 1 Foundation

You are a Senior Product Designer, Senior UI/UX Designer, Healthcare SaaS Architect, and React Engineer.

Build the foundation of a premium healthcare operating system called RiayahOS for Riayah Care, an international medical tourism company that connects GCC patients with leading hospitals in Kerala, India.

This is not a generic CRM. It should look and feel like a premium enterprise application comparable to Linear, Stripe Dashboard, Vercel, Notion, or modern hospital management systems.

Design Goal

The user should immediately feel:

Premium

Clean

Trustworthy

Healthcare-focused

Enterprise-grade

Executive-level

Fast and modern

Avoid dashboard templates.

Avoid excessive colors.

Avoid clutter.

The design should be spacious, elegant, and highly readable.
